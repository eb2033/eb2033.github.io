Background

I am a Russian who grew up living in Ireland. I am currently studying omputer networks and cybersecurity in the Technological university of the Shannon. I love to experiment with linux environments and security tooling.

Skills & Technologies

My main languages are Python, YML and PHP with brief exposure to SQL, C++ and Javascript. I frequently use the docker engine and Docker Compose on my homelab environments and am planning to expand that with Ansible and Terraform.

Philosophy

I believe in secure architecture design and defense in depth. When a system is inevitably compromised in one way or another, the goal isn't to prevent every intrusion—it's to ensure that compromise is detected quickly, contained effectively, and recoverable without catastrophe. Security isn't a wall you build once; it's a posture you maintain: layered controls, strong visibility, and the assumption that any single control can fail.

> projects

$ bot-watching

A monitoring pipeline for a Cowrie SSH/Telnet honeypot. A Python engine parses session logs, runs detection rules (brute force, bad credentials, suspicious commands, file downloads), enriches attacker IPs with GeoLite2 geolocation and stores it all in PostgreSQL. Grafana dashboards read it through a SELECT-only database role.

Python PostgreSQL Docker Grafana Cowrie
$ snekfarm

An idle browser game about farming snakes, with a playable Snake maze minigame and three prestige layers. Game rules live in a DOM-free engine, so the economy can be tested headlessly (373 tests). An optional hardened Node.js server adds anonymous cloud saves and ships as a Docker image.

JavaScript Node.js Docker Python
$ python-network-scanner

An interactive Linux command-line front end for Nmap built on python-nmap. You choose SYN scans, top-port or full-port sweeps, service and OS detection or custom port ranges from a menu, then optionally export the results to JSON.

Python Nmap Linux
$ dsp-with-python

Digital signal processing notebooks from college coursework. They cover AM, ASK, QPSK and 8-QAM modulation and demodulation, FFT spectrum analysis and noise simulation, with results plotted on constellation diagrams.
